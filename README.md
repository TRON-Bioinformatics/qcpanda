# qcpanda
TRON/qcpanda is a Nextflow (DSL2) pipeline that runs a comprehensive battery of QC tools — SeqKit, FastQC, Sequali, fastp, SortMeRNA, FastQ Screen, Kraken2/Bracken, and NGSCheckMate — on paired-end or single-end FASTQ data and aggregates all results into a single interactive MultiQC report.
